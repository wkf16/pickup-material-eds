6514 使用 / 调试教程

guide

1. 启动机器

确认实验室主机 Dell Precision 3660 已上电、网线正常，并且能从你这边通到 203-precision3660 / 10.24.32.98（或 Tailscale 100.110.247.81）。

SSH 进机：ssh a203@203-precision3660。WebUI 默认在 :80，浏览器开 http://10.24.32.98 即可（端口已不需要带）。

2. 基础接线

6514 通过 RS-232 USB 串口接主机，链路 9600 / 8N1 / XonXoff / CR。在远端 Linux 上是 /dev/ttyUSB0（pl2303）。

采集链路：6514 后面板 2V ANALOG OUTPUT 走 BNC 到 USB-6002，DAQ 端用 AI0 DIFF。传感器接 6514 三轴输入，屏蔽接 COMMON。线缆固定，避免摩擦电噪声。

3. 调零接线（输入短路）

调零阶段不要先接传感器。最稳妥的做法是给 6514 输入装三轴短路帽，或把中心导体与屏蔽短接，构造"输入短路"状态，让 Zero Check 和 Zero Correct 在已知零输入下完成。

已经接了传感器就先断开再调零。带漂移源直接做零校准会得到错的零点。

4. 标准调零顺序

  1. *RST + *CLS 重置 + 清状态
  2. SYST:ZCH ON 进 Zero Check
  3. FUNC "VOLT"，再 VOLT:RANG 2 或 20
  4. 关辅助：VOLT:RANG:AUTO OFF、SYST:AZER OFF、AVER:STAT OFF
  5. SYST:ZCOR ON 触发零点校准
  6. SYST:ZCH OFF 退出，进入正常测量

校完用 FUNC?、VOLT:RANG?、SYST:ZCH?、SYST:ZCOR? 回读确认。

5. 测量前的快速自检

SCPI 控制台按这个顺序点一遍：*IDN? → SYST:ZCH OFF → FUNC? → VOLT:RANG? → READ?。任意一条飘红或返回奇怪值，先排串口/状态再继续。

READ? 返回三段 <reading>,<timestamp>,<status>，例如 -7.33E-06,+1.25E+04,+0E+00。Zero Check 没关掉时这条会返回空。

6. 录制流程

自检都过之后，在 WebUI 录制卡片填 Label 和 Duration 点开始。当前后端落盘走 .npz，元数据走 SQLite。

命令行裸采集：python scripts/capture_freqresp.py --duration 12 --range 2 --out data/exp01/test.npy。看到提示后再播激励信号。

7. 常见错误

拿不到 *IDN?：先怀疑 COM 口 / 波特率 / Xon/Xoff / 终止符是否还是 CR。/dev/ttyUSB0 不存在则看 docs/dev-real-hardware.md §6。

读数飘得离谱：没短路调零、屏蔽没接 COMMON、线缆在动、量程顶满，按此顺序排。

波形空：6514 → USB-6002 的 BNC 没接好，DAQ 不在差分模式，或采样率/缓冲设置异常。

8. 后端 API 接口落位 phase 2

WebUI ↔ FastAPI ↔ 6514/DAQ 的接口契约：

  • GET /api/state 当前整机状态
  • POST /api/control/{function,range,zero-check,zero-correct,scpi/send}
  • POST /api/recording/{start,stop} 录制生命周期
  • GET /api/data/* 列表/预览/下载
  • WS /ws/{stream,state} 波形流 + 状态推送
  • WS /ws/snapshot 占位

9. SCPI · 通用 + 测量 + 调零 实测可用

真机全识别。✅ = UI 快速按钮已暴露；📝 = 控制台手输。

  • ✅ *IDN?　识别仪器
  • ✅ *RST　恢复 GPIB 默认
  • 📝 *CLS · *ESR?　清/查状态
  • 📝 FUNC "VOLT"|"CURR"|"RES"|"CHAR"　切功能
  • ✅ FUNC?　查功能
  • 📝 VOLT:RANG <n>　设量程
  • ✅ VOLT:RANG?　查量程（必须带 FUNC 前缀）
  • ✅ VOLT:RANG:AUTO ON　自动量程
  • ✅ SYST:ZCH ON|OFF　Zero Check
  • ✅ SYST:ZCOR ON　Zero Correct
  • 📝 SYST:ZCH? · SYST:ZCOR?　查状态
  • 📝 SYST:AZER ON|OFF　Auto Zero（关掉提速）
  • ✅ READ?　触发并读一笔

10. SCPI · 速率 / 滤波 / 显示 实测可用 · 待暴露

真机都识别，UI 暂未做按钮，控制台手输即可。完整后端会把这些接进控制卡片。

  • VOLT:NPLC <n>　集成时间 0.01-10 PLC（噪声 vs 速度）
  • CURR:NPLC / RES:NPLC / CHAR:NPLC　各功能独立
  • DISP:DIG <n>　显示位数 4-7（默认 6）
  • MED:STAT ON|OFF + MED:RANK 1-5　中位数滤波
  • AVER:STAT ON|OFF + AVER:COUN 1-100　数字滤波
  • AVER:TCON MOV|REP　移动平均 / 重复
  • CALC2:NULL:STAT ON　REL（基线相减）

11. SCPI · Buffer / Limit / Math 留给完整后端

这一组与 WebUI 现有 ring buffer / 录制 / 后处理重叠。建议在 WebUI 侧做，不在仪器侧（更灵活）。

  • Buffer　TRAC:CLE、TRAC:POIN <1-2500>、TRAC:FEED SENS、TRAC:DATA?、FORM:ELEM READ,TIME,STAT
  • Buffer 统计　CALC3:FORM MIN|MAX|MEAN|SDEV|PKPK + CALC3:DATA?
  • Limit　CALC2:LIM:STAT、CALC2:LIM:LOW/UPP、CALC2:LIM:FAIL?（同 LIMit2）
  • Math　CALC:FORM MXB|PERC、CALC:KMAT:MMF/MBF/MUN/PER、CALC:STAT ON、CALC:DATA?
  • Guard　VOLT:GUAR ON / RES:GUAR ON　高阻抗驱动屏蔽

12. 完整后端实施优先级 roadmap

下次写真机 BenchService 时按这个顺序补，性价比最高（详见 docs/dev-real-hardware.md §5.6）：

  1. Auto range + NPLC　用户最常调的两个旋钮
  2. Filter（AVER:*、MED:*）　噪声测试场景必需
  3. :INIT + :READ? 拆开　让 WebUI 触发与读取解耦
  4. Buffer（TRAC:*）　仅当要替换 ring buffer 才碰
  5. Math / Limit　仪器端 vs WebUI 后处理是个权衡，多数场景后者更灵活
