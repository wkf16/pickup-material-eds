6514 使用 / 调试教程

guide

1. 启动机器

先确认实验室主机 Dell Precision 3660 已上电，网线正常，等它回到内网。若你在本机上远程操作，先确认能通 203-precision3660 或 10.24.32.98。

远程登录建议直接用 ssh a203@203-precision3660。若只在内网可达，也可以用 ssh [email protected]。进机后先看 python3 --version 和 webui 服务是否在 :8000。

2. 基础接线

6514 通过 RS-232 USB 串口接主机，默认链路是 9600 / 8N1 / XonXoff / CR。采集链路是 6514 后面板 2V ANALOG OUTPUT 走 BNC 到 USB-6002，DAQ 端建议用 AI0 DIFF。

传感器接 6514 三轴输入，铜箔屏蔽或参考屏蔽层接 COMMON。若是做空气麦或贴喇叭实验，线缆一定要先固定，避免摩擦电噪声。

3. 调零时怎么接

调零阶段不要先接传感器。最稳妥的做法是给 6514 输入上三轴短路帽，或者把中心导体与屏蔽短接，形成"输入短路"状态。这样做是为了让 Zero Check 和 Zero Correct 在已知零输入下完成。

如果已经接了传感器，先断开传感器，再调零；不要带着漂移源直接做零校准。调零完成后，再恢复传感器和 DAQ 链路。

4. 标准调零顺序

推荐顺序直接按现有脚本和实验文档来：*RST → *CLS → SYST:ZCH ON → FUNC "VOLT" → VOLT:RANG 2 或 20 → 关闭 AUTO RANGE / AZER / 数字滤波 → SYST:ZCOR ON → SYST:ZCH OFF。

调零完成后立刻用 FUNC?、RANG?、SYST:ZCH?、SYST:ZCOR? 回读确认，不要只凭前面板感觉。

5. 开始测量前的检查

先发 *IDN?，确认回传里有 MODEL 6514 和序列号。再确认当前功能、量程、Zero Check 状态都对。若是看模拟输出链路，优先用 VOLT 模式，小信号先锁 2V，不够再升到 20V。

如果是 USB-6002 同步采集，确认 BNC 已接，DAQ 侧是差分输入，采样率先从 5 kS/s 或 10 kS/s 起，不要一上来就堆到最大。

6. 录制与调试

录制前先用下面的 COM/SCPI 控制台跑一遍 *IDN?、FUNC?、RANG?、READ?。只有这些都正常，才点录制。这样出现问题时能快速判断是串口、量程、还是采样链路的问题。

如果需要跑仓库里的裸脚本，可在实验机上执行 python scripts/capture_freqresp.py --duration 12 --range 2 --out data/exp01/test.npy。看到提示后再播激励信号。

7. 常用命令速查

  • *IDN? 识别仪器和序列号
  • FUNC? / FUNC "VOLT" 查询或切换功能
  • VOLT:RANG? / VOLT:RANG 2 查询或设置量程
  • SYST:ZCH ON|OFF 开关 Zero Check
  • SYST:ZCOR ON 做一次 Zero Correct
  • READ? 拉一笔当前读数

8. 常见错误

拿不到 *IDN? 时，优先怀疑 COM 口、波特率、Xon/Xoff、终止符是否还是 CR。读数漂得离谱时，优先怀疑没短路调零、屏蔽没接 COMMON、线缆在动、或者量程太小导致顶满。

若 WebUI 控制正常但采样没有波形，优先看 6514 到 USB-6002 的 BNC 是否接好，再看 DAQ 是否在差分模式，最后再查采样率和缓冲。

9. 接口落位 phase 2

WebUI ↔ 后端 ↔ 6514/DAQ 这条链路目前规划的接口如下，调试时可以按此核对实际对接进度。

  • GET /api/state 当前整机状态
  • POST /api/control/* 功能/量程/zero-check/zero-correct
  • POST /api/recording/{start,stop} 录制生命周期
  • GET /api/data/* 数据列表、预览、下载
  • /ws/stream 滚动波形流
  • /ws/state 状态变更推送
  • /ws/snapshot 已占位，待真实触发逻辑接入
