# 实验 01:测试 SLTS 类 TENG 材料的实际带宽上限

> **状态**:计划中
> **预计时长**:一个上午(2-3 小时)
> **关联硬件**:Keithley 6514 + NI USB-6002 + 自备喇叭
> **关联论文**:Zhang et al., *Chem. Eng. J.* 524 (2025) 169299 ([SLTS](https://doi.org/10.1016/j.cej.2025.169299))

## 1. 问题与假设

### 起因
论文里 SLTS 传感器贴在喉咙上,频谱图只展示到 500 Hz,作者将其定位为 *laryngeal vibration sensor*。
我之前贴喉咙采样,看到信号在 2 kHz 像混叠,怀疑是带宽不够;现在意识到那是 50 Hz 工频干扰 +
USB-6002 没抗混叠 → 高频噪声折叠造成的伪象,**信号本身确实在 sub-500 Hz**——但**那只能说明
"贴喉咙工况下"这样**,不能说明材料本身没有 kHz 响应。

### 假设 H1
> SLTS 这种 PDMS+BST / 银纤维布 / Cu 三层 TENG 结构,**在脱离皮肤束缚的工况下**,可以响应到至少 1-2 kHz。
> 如果成立,这个材料就有"做空气麦"的潜力(论文未涉及)。

### 假设 H0(零假设)
> 这种结构的固有机械-电学时间常数就是 ms 级,即使脱离皮肤,> 500 Hz 也无显著响应。

## 2. 物理背景:为什么贴喉咙看不见 kHz

皮肤+肌肉是高阻尼黏弹介质,机械传递函数本身就是低通,2-3 kHz 衰减 -20 dB 起。**贴喉咙时,无论材料
带宽多高,你看到的都是"皮肤过滤后的"信号,不是材料本身**。

| 频率 | 皮肤组织传递率 | 贴喉咙能看到? |
|---|---|---|
| 50 Hz | ~100% | ✅ |
| 200 Hz | ~80% | ✅ |
| 500 Hz | ~30% | ⚠ 弱 |
| 1 kHz | ~10% | ❌ |
| 5 kHz | <1% | ❌ |
| 10 kHz | ~0% | ❌ |

要测**材料本身**的带宽,必须**拿掉皮肤这层阻尼**。

## 3. 三种耦合方式与本实验的设计逻辑

| 耦合方式 | 说明 | 本实验目的 |
|---|---|---|
| **接触式机械耦合**(贴喉咙) | 论文工况;受皮肤阻尼限制 | 已知,不重测 |
| **直接机械驱动**(贴喇叭纸盆) | 喇叭以已知频率振动→强制带动传感器 | **测材料的电学+内部机械响应极限** |
| **空气声压耦合**(传感器悬空) | 模拟空气麦工况;同时受空气耦合效率影响 | **测它能不能当空气麦用** |

> **关键洞察**:这两个测试**都要做**,顺序也很重要。如果方法 B 没看到 kHz,**直接结束**——
> 是材料本身的问题,空气耦合再好也救不回来。如果 B 看到了,再做 C 比对,得到的差距就是
> "空气耦合效率"这个独立的工程量。

### 5.2 6514 配置(每次实验前一次性发完)

```
*RST                    # 软复位
*CLS                    # 清状态
SYST:ZCH ON             # 开零检,接线安全
FUNC "VOLT"             # 选电压模式
VOLT:RANG 2             # 锁 2V 量程(信号大就改 20)
VOLT:RANG:AUTO OFF      # 强制关自动量程
SYST:AZER OFF           # 关 AutoZero(连续采样)
AVER:STAT OFF           # 关数字均值滤波
MEDN:STAT OFF           # 关中值滤波
DISP:ENAB OFF           # 关前面板显示(可选,提速)
SYST:ZCOR ON            # 做一次零校准
SYST:ZCH OFF            # 关零检,开始测量
```

⚠ **GRD 引导**:本实验 **不开**(`SYST:GRD OFF` 默认就是)。GRD 主要为消除三轴线漏电干扰
高阻测量,空气麦场景反而可能引入震荡。

### 5.3 USB-6002 配置

| 参数 | 值 | 备注 |
|---|---|---|
| Channel | `Dev1/ai0` | 实际设备名以 `nidaqmx` 列出为准 |
| Terminal | `DIFF` 差分 | 抗共模 56 dB,远好于单端 |
| Range | ±10 V | USB-6002 固定无法换 |
| Sample rate | **50 kS/s** | 满速,Nyquist 25 kHz 覆盖音频 |
| Sample mode | CONTINUOUS | |
| Host buffer | 100 k 样本 (≈ 2 s) | 防 USB 中断丢点 |

**抗混叠 LPF 这次先不加**——本实验目的就是看 kHz 响应有没有,加了 700 Hz LPF 直接砍掉。
等确认信号特性后再决定是否插。

## 6. 执行流程(每步看结果再下一步)

### Step 0 ── 基线(短路噪声地板,5 min)
1. 6514 输入用三轴短路帽短路,**不接传感器**
2. 跑 `capture_freqresp.py --duration 10`,**不放音**
3. 看时域 + FFT
4. **预期**:
   - 时域峰峰 < 5 mV
   - FFT 主要看到 50/100/150 Hz 工频谐波
   - 1 kHz 以上接近本底噪声(应该 < 0.1 mV/√Hz)
5. **不达预期**:仪器/线缆问题,先解决再继续(检查共地、屏蔽、电源、附近大功率设备)

### Step 1 ── 1 kHz 单音(go/no-go,5 min)
1. **方法 A**:传感器双面胶贴喇叭纸盆中央,中间夹铜箔屏蔽(铜箔接 6514 COMMON)
2. 笔记本播 1 kHz 纯音 (`play -n synth 5 sine 1000` 或随便一个 1k.wav)
3. 在 6514 **前面板** 看读数:开声 / 不开声,读数有没有可见变化(>10 mV)
4. **判断**:
   - **有变化** → 假设可能成立,进入 Step 2
   - **完全无变化** → 强烈不利证据,但还是跑 Step 2 用 FFT 仔细看,然后停止

### Step 2 ── 对数扫频 Bode(主测,30 min)
1. 在 Mac 跑 `gen_chirp.py`,生成 `chirp_50_20k_10s.wav`
2. 喇叭播放该文件
3. **同时** Lab Linux 跑 `capture_freqresp.py --duration 12`
4. 之后跑 `analyze_bode.py capture.npy --plot`
5. 输出:`bode.png`(时域 + 频谱 + 1/3 倍频程能量分布)

### Step 3 ── 方法 C 空气耦合(只在 Step 2 看到 ≥1 kHz 响应才做,30 min)
1. 撕掉双面胶,改成晾衣夹夹住传感器一角悬空
2. 传感器正面对喇叭,距离 5 cm
3. 喇叭和传感器之间不要放铜箔(此时空气是耦合介质)
4. 重复 Step 2 的扫频 + 采集 + 分析
5. **比较 Step 2 (机械直驱) 和 Step 3 (空气耦合) 的频响**:
   - Step 2 平到 5 kHz 但 Step 3 只到 500 Hz → 是空气耦合效率问题,材料本身可以
   - Step 2 和 Step 3 都早早衰减 → 材料带宽就是这个量级

### Step 4(可选) ── 真实语音
- 对着传感器(夹空 30 cm)说话 10 秒
- 把采到的 .npy 转成 wav 放出来听
- 看声谱图,主观判断能不能区分音节

## 7. 评判标准与下一步决策

| Step 2 + 3 结果 | 物理结论 | 工程结论 | 下一步 |
|---|---|---|---|
| 两者都在 200 Hz 以下 | 材料就是 sub-kHz | 论文范围内 | 转向接触式振动传感方向 |
| Step 2 平到 1-3 kHz,Step 3 衰减早 | 材料有 kHz 能力,**空气耦合是瓶颈** | 改器件结构(悬膜+后腔)有戏 | 文献调研 TENG 空气麦的结构 |
| Step 2 + 3 都平到 5 kHz+ | **材料 + 当前结构都能做空气麦** | 论文 follow-up 机会 | 做完整 SPL/SNR 表征 + 申请期刊 |
| Step 2 平到 1 kHz 但 Step 3 也接近 | 矛盾,可能空气耦合恰好合适 | 反复验证,排除测量误差 | 换喇叭/距离重测 |

## 8. 已知陷阱

### 物理层
- **传感器质量加在喇叭纸盆上**:论文 1.2 g,几乎不影响,但若你的样品大于 5 g,纸盆会拖累
- **喇叭非线性失真**:小音箱在大音量下 THD 高,扫频高频段输出已经失真,导致 Bode 不准
  → 用参考麦同步采,Bode = TENG/REF,失真就被消掉
- **房间驻波**:在小房间扫频,1 kHz 以上有强驻波。**贴喇叭的 Step 1/2 不受影响**,Step 3 受影响
- **传感器引线变形**:线缆动会产生摩擦电(triboelectric)噪声。固定线缆到桌面

### 电学层
- **喇叭线的电压会通过空间耦合到 TENG 电极**(几 V 交流): 铜箔屏蔽 + 共地 解决
- **磁场**:喇叭背后磁体很强,线缆别绕过去
- **6514 V 模式实际带宽**:输入电容 ~10 pF + 三轴线 ~60 pF/m。对 1 GΩ 源阻抗,系统极点
  ~1.6 Hz(高通);TΩ 源阻抗就更低,所以低频不是问题。**高频侧极限暂未量,由材料决定**
- **2V ANALOG OUTPUT 自己的带宽**:跟 6514 V 模式的带宽一致,manual 没明确给数字,经验是 kHz 量级,
  这恰好是这次实验要量的东西之一

### 软件层
- **DAQ 缓冲不足**:Fs=50 kS/s,小 FIFO (2047 样本) 要求主机及时取走。**关闭 GUI、屏保**
- **时间不严格同步**:笔记本播放 + Lab 采样不在同一时钟域。**用扫频不用单音**就能容忍
- **wav 头**:32-bit float wav 在某些播放器不兼容,生成时用 16-bit PCM
